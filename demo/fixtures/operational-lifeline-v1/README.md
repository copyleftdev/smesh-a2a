# Operational LIFELINE capture v1

This fixture is generated by `scripts/generate-operational-lifeline.sh` from the real loopback-only LIFELINE failure scenario. It is the production default for `/operational.html`; `../operational-observatory-v1/` remains the two-event projection contract fixture.

The run resolves six Agent Cards/gateway endpoints. The checked deployment names five providers because Atlas Cold Chain owns both the independent primary and fallback gateway endpoints; this package does not relabel either endpoint as a sixth organization.

Public browser files are `package.jsonl`, `receipt.json`, `actors.json`, `editorial.json`, and `browser-bootstrap.json`. `public-manifest.json` records privacy projection receipts. The `restricted/` directory contains the canonical capture, causal source, sealed replay and receipt, privacy evidence, source evidence manifest, and frozen scripted test-human review/decision receipts. The decision authorizes only the canonical pre-decision prefix and candidate; the final replay seal authenticates subsequent inclusion of the returned decision receipt. It is not an authenticated or live-human decision and does not claim mTLS. The mutable ratification database and raw scenario inputs are intentionally not retained.

Source schemas provide ordered events but no authoritative wall-clock timestamps, so browser time is explicitly an adapter-ordinal presentation schedule. Scheduler-dependent runtime tick ordinals/counts are normalized to kind-only observations. Five ephemeral SMESH signal hashes remain absent as `null`; `restricted/source-facts.json` binds five explicit `subjectId` unavailable restrictions to the exact event/content digests. No replacement identity is invented. The same manifest binds closed failure kinds and public-safe outcomes without exposing raw payloads, and the counts agree with `restricted/evidence-manifest.json`.

All data is fictional local exercise evidence. It authorizes no medical, shipping, quarantine, outreach, or other real-world action.
